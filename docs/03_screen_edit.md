# 03. 編集画面 仕様

画面ID: `editPage`
モック該当箇所: `index.html:990-1078`

## 画面の役割

既存の棚卸商品マスタの一部属性を編集する。
編集可能なのは「棚卸ステータス」「費目」「単位」「税区分」で、登録経路・発注先・発注対象・商品名・商品コードは編集不可とする。

## 遷移元
- 一覧画面のアクション「編集」ボタン

## 戻り
- 「← 棚卸商品管理に戻る」リンク → 一覧画面
- パンくず経由 → 一覧画面

## 画面構成要素

### ヘッダ
- 戻るリンク
- ページタイトル(動的): 編集対象の商品名
- パンくず: `棚卸管理 ＞ 棚卸商品管理 ＞ {商品名}`

### フォーム

| 項目 | 種別 | 必須 | 編集可否 | 備考 |
|---|---|---|---|---|
| 登録経路 | テキスト | - | **不可** | `disabled` 入力。表示はラベル名(例: `インフォマート連携`) |
| 発注先 | テキスト | - | **不可** | `disabled` |
| 商品名 | テキスト | - | **不可** | `disabled` |
| 商品コード | テキスト | - | **不可** | `disabled`。空なら空欄 |
| 発注対象 | テキスト | - | **不可** | `disabled`。`発注対象`/`発注対象外`(`orderOn`)。棚卸とは独立属性で本画面では参照のみ |
| 棚卸ステータス | トグルスイッチ | 必須 | 可 | ON=表示(緑) / OFF=非表示(グレー)。ラベルテキスト連動 |
| 費目 | セレクト | 必須 | **自社加工品のみ** | 固定3区分（食材/飲料/資材）から選択。**費目欄は自社加工品(`route='in-house'`)の編集時のみ表示**。連携・発注商品では費目欄ごと非表示（費目はデータ画面で参照可）。モック: `editCategoryRow` を in-house のときのみ表示 |
| 単位 | セレクト | 必須 | 可 | 選択肢: `個` `パック` `本` `箱` `樽` `kg` `g` `L` `ml` |
| 税区分 | セレクト | 必須 | 可 | 選択肢: `外税（標準税率）` `外税（軽減税率）` `内税（標準税率）` `内税（軽減税率）` `非課税` |

ラベル右の `（必須）` バッジは赤文字で表示。

### フッタ
左右配置のボタン:
- **削除する**(赤枠) — 確認ダイアログ「この商品を棚卸対象から削除しますか？」 → OKで一覧画面に戻る
  - モック実装: 実際の配列からの削除は未実装、確認のみ
- **更新する**(緑塗り) — 編集内容を商品データに反映し、一覧画面に戻る + トースト「更新しました」

## バリデーション

モックでは必須項目はトグル + セレクトのみで、いずれもデフォルト値があるため未入力エラーは発生しない。
本実装では以下を想定:
- 単位・税区分: 必須(セレクト)
- 棚卸ステータス: 必須(トグル、デフォルト値あり)

## 費目設定ができる場所
費目を設定・変更できるのは、**(1) 新規追加画面（自社加工品の新規登録）** と **(2) 編集画面（自社加工品のみ）** の2か所のみ。
連携・発注システム商品の費目は自動付与で、**編集画面では費目欄を表示しない**（費目はデータ画面で参照可）。

## 既登録（AI判定／発注分）を自社加工品に変更したい場合
編集での経路変更は不可。非自社加工品の編集画面には案内バナーを表示する：
> 「自社加工品に変更したい場合は、この商品を削除し、自社加工品として新規登録してください。」
（モック: `editConvertNote` を `route !== 'in-house'` のとき表示）

## 編集対象外項目を変更したい場合

登録経路・発注先・商品名・商品コードはこの画面では変更不可。
これらは登録経路ごとに以下の運用となる想定:
- インフォマート連携: 連携先のマスタ更新で反映
- 納品書書き起こし: 書き起こし側で再登録/修正
- 発注アプリ連携: 発注アプリのマスタ更新で反映
- 自社加工品: 新規追加画面で登録時にのみ設定可能(削除→新規追加で対応)
