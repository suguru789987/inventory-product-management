# 04. 新規追加画面 仕様

画面ID: `addPage`
モック該当箇所: `index.html:1083-1165`

## 画面の役割

棚卸商品マスタに **自社加工品** を手動で追加する。
インフォマート連携・納品書書き起こし・発注アプリ連携の3経路は自動でマスタが作成されるため、この画面で扱うのは「自社加工品」固定とする。

## 遷移元
- 一覧画面の「商品を追加する」ボタン

## 戻り
- 「← 棚卸商品管理に戻る」リンク → 一覧画面
- 「キャンセル」ボタン → 一覧画面(入力破棄)
- 「登録する」成功時 → 一覧画面 + トースト「商品を登録しました」

## 画面構成要素

### ヘッダ
- 戻るリンク
- ページタイトル: 「新規商品追加」
- パンくず: `棚卸管理 ＞ 棚卸商品管理 ＞ 新規商品追加`

### フォーム

| 項目 | 種別 | 必須 | 備考 |
|---|---|---|---|
| 商品名 | テキスト | **必須** | プレースホルダ「商品名を入力してください」 |
| 商品コード | テキスト | 任意 | プレースホルダ「商品コードを入力してください」 |
| 棚卸ステータス | トグル | **必須** | デフォルトON(表示)、ラベル連動。「発注対象にはならない」旨を補足表示 |
| 費目 | セレクト | **必須** | 費用設定の変動費目から選択。**自社加工品の費目を確定できるのは、この新規登録画面と編集画面（自社加工品のみ）の2か所のみ**。AI推定フォールバックなし |
| 単位 | セレクト | **必須** | デフォルト「選択してください」(`disabled selected`)。選択肢は編集画面と同一 |
| 税区分 | セレクト | **必須** | デフォルト「選択してください」。選択肢は編集画面と同一 |

ラベル右の `（必須）` は赤文字、`（任意）` はグレー文字。

### フッタ
- **キャンセル**(白背景) → 一覧画面(破棄)
- **登録する**(緑塗り) → バリデーション → 商品マスタに追加 → 一覧画面

## バリデーション

「登録する」押下時:
1. 商品名が空 → `alert('商品名を入力してください')`
2. 費目が未選択 → `alert('費目を選択してください')`
3. 単位が未選択 → `alert('単位を選択してください')`
4. 税区分が未選択 → `alert('税区分を選択してください')`

すべて通過すれば登録処理に進む。

## 登録時の自動付与項目

ユーザー入力に加え、以下を自動で設定する:

| 項目 | 自動付与値 |
|---|---|
| `id` | 既存最大ID + 1 |
| `route` | `'in-house'` (自社加工品) 固定 |
| `supplier` | `'（自社加工品）'` (発注先なし) |
| `orderOn` | `false` (発注対象外。棚卸商品として登録) |
| `price` | `0` (棚卸推奨単価未設定) |

## デザイン方針

- 編集画面と同じフォームレイアウト(`edit-section` / `edit-row` 等)を流用
- 必須項目は入力欄のラベルで明示し、押下時のalertで検証
- 自社加工品である旨は明示しない(ユーザーは「商品追加」操作と認識すればよく、登録経路は裏側で固定)
