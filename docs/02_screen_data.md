# 02. データ画面(閲覧) 仕様

画面ID: `dataPage`
モック該当箇所: `index.html:892-985`

## 画面の役割

個別商品の詳細データを **閲覧専用** で表示する。編集はせず、棚卸履歴・納品書書き起こし履歴も合わせて確認できる。

## 遷移元
- 一覧画面の行クリック
- 一覧画面のアクション「データ」ボタン

## 戻り
- 「← 棚卸商品管理に戻る」リンク → 一覧画面
- パンくずの「棚卸管理」「棚卸商品管理」リンク → 一覧画面

## 画面構成要素

### ヘッダ
- 戻るリンク: 「← 棚卸商品管理に戻る」
- ページタイトル: 「棚卸商品データ」
- パンくず: `棚卸管理 ＞ 棚卸商品管理 ＞ {商品名}`

### セクション①: 商品データ

ラベル(左180px固定幅) + 値(右) の縦並び。値は閲覧のみ・編集不可。

| 項目 | 表示内容 |
|---|---|
| 発注先 | 発注先名(プレーンテキスト) |
| 商品名 | 商品名 |
| 商品コード | 商品コード、空なら `-` |
| 棚卸ステータス | 「表示」/「非表示」(プレーンテキスト) |
| 発注対象 | 「発注対象」/「発注対象外」(`orderOn`。閲覧のみ) |
| 費目 | 費目文字列(`category`) |
| 単位 | 単位文字列(`個`/`パック`/`本`/`箱`/`樽`/`kg`/`g`/`L`/`ml`) |
| 税区分 | 税区分文字列 |

### セクション②: 棚卸し参考データ

| 項目 | 表示内容 |
|---|---|
| 棚卸し推奨単価 | 直近の棚卸データから取得した単価(円)。0円なら `0円` |
| 補足テキスト | 「直近の棚卸データ（YYYY年M月D日）での単価です。」 |

### セクション③: 棚卸し履歴(左)

過去の棚卸実施記録を新しい順に一覧表示。

| 列 | 内容 |
|---|---|
| 実施日 | YYYY-MM-DD |
| 在庫数量 | 小数1桁 |
| 商品単価 | 円(カンマ区切り) |
| 小計 | 円(カンマ区切り) |

モックでは2件のサンプルを固定表示(2026-02-28, 2026-01-31)。

### セクション④: 納品書書き起こし履歴(右)

過去の納品書書き起こし記録を新しい順に一覧表示。

| 列 | 内容 |
|---|---|
| 納品日 | YYYY-MM-DD |
| 数量 | 整数 |
| 納品単価 | 円(カンマ区切り) |
| 小計（税別） | 円(カンマ区切り) |

モックでは2件のサンプルを固定表示(2026-02-25, 2026-02-10)。
セクション③④は2カラムグリッド(`detail-columns`)で左右並列に配置。

## デザイン方針

- 編集UIは一切なし(`input` 等を出さない)
- 「登録経路」はUIに出さない（J-004 で撤廃。`route` は内部分類としてのみ保持）
