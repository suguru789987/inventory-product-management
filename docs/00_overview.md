# 00. 概要

## 機能の目的

ラクミー経営管理における **棚卸商品管理** 機能は、店舗ごとの棚卸対象となる商品マスタを一元管理するための画面群を提供する。
棚卸し業務に必要な「対象商品の選定」「単位・税区分の設定」「棚卸履歴・納品履歴の確認」をユーザー(店舗運営担当者・経営者)が完結できることを目指す。

## 想定ユーザー

- 店舗運営担当者（棚卸し業務の主担当）
- 経営者・経営管理担当者（棚卸対象マスタ整備の責任者）
- カスタマーサクセス（顧客の棚卸設定支援時に参照）

## 画面構成

本機能は4画面のSPA(モックは単独HTMLで4ページ切替を実装)で構成される。

| ID | 画面名 | 役割 |
|---|---|---|
| `listPage` | 一覧画面 | 棚卸商品の一覧表示・検索・絞込・一括操作 |
| `dataPage` | データ画面(閲覧) | 個別商品の詳細情報・棚卸履歴・納品書履歴の閲覧 |
| `editPage` | 編集画面 | 棚卸ステータス/単位/税区分の編集 |
| `addPage` | 新規追加画面 | 棚卸登録商品等を手動で商品マスタに追加 |

## 画面遷移

- 一覧画面はすべての起点。グローバルヘッダの「棚卸管理 > 棚卸商品管理」ナビから到達。
- 一覧画面の行クリック / 「データ」アクション → データ画面 へ遷移。
- 一覧画面の「編集」アクション → 編集画面 へ遷移。
- 一覧画面の「商品を追加する」ボタン → 新規追加画面 へ遷移。
- データ画面 / 編集画面 / 新規追加画面 のいずれも「← 棚卸商品管理に戻る」リンクおよびパンくず経由で一覧画面に戻る。
- 編集画面で「更新する」を押下 → 一覧画面に戻る + トースト「更新しました」。
- 編集画面で「削除する」を押下 → 確認ダイアログ → OKで一覧画面に戻る(モックでは削除自体は実装せず確認のみ)。
- 新規追加画面で「登録する」を押下 → 一覧画面に戻る + トースト「商品を登録しました」。
- 新規追加画面で「キャンセル」を押下 → 一覧画面に戻る(入力破棄)。

## 用語

| 用語 | 意味 |
|---|---|
| 棚卸対象 | 棚卸し作業時にカウント対象とする商品(=棚卸ステータス「表示」のもの) |
| 登録経路（内部分類） | 商品マスタへのデータ登録源。インフォマート連携 / 納品書書き起こし / 発注アプリ連携 / 棚卸登録商品 の4(設計上は5)分類。**UI には出さない**（J-004） |
| 棚卸推奨単価 | 直近の棚卸データから取得した参考単価。棚卸入力時の初期値候補 |
