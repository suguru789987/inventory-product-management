# 01. 一覧画面 仕様

画面ID: `listPage`
モック該当箇所: `index.html:785-887`

## 画面の役割

棚卸商品マスタの一覧表示と、検索・絞込・一括操作・個別操作・新規追加の起点となる中心画面。

## 画面構成要素

### グローバルヘッダ
- ラクミーロゴ + 「経営管理」テキスト
- 店舗セレクタ（モックは「なかめのてっぺん 渋谷ストリーム」固定）
- ヘルプアイコン / ユーザーアイコン / メニューアイコン

### ページヘッダ
- パンくず: `棚卸管理 ＞ 棚卸商品管理`
- ページタイトル: 「棚卸商品管理」
- 右端: 「商品を追加する」ボタン → `addPage` へ遷移

### ツールバー
左側:
- **商品名検索ボックス** (`#searchInput`): プレースホルダ「商品名で検索」。入力ごとにリアルタイムフィルタ(部分一致、大文字小文字区別なし)。

右側:
- **棚卸ステータスフィルタ** (`input[name="inventoryStatus"]`): ラジオボタン。
  - すべて (`all`、デフォルト)
  - 表示 (`on`)
  - 非表示 (`off`)

### 一括操作バー (`#bulkBar`)
- チェックボックスで1件以上選択されたときのみ表示
- 左: 「N件選択中」表示
- 右ボタン:
  - 「一括：表示にする」 → 選択行の `inventoryOn = true`
  - 「一括：非表示にする」 → 選択行の `inventoryOn = false`
- 操作後、選択解除 + 一覧再描画 + トースト「表示に変更しました」「非表示に変更しました」

### サマリー行
- `全 N 件 / 棚卸表示 N 件 / 棚卸非表示 N 件`
- ※フィルタ適用後の絞込件数ではなく、商品マスタ全体の件数を表示する

### テーブル

| 列 | 内容 | 備考 |
|---|---|---|
| チェックボックス | 一括操作用の選択 | ヘッダクリックで全選択/全解除 |
| (ドラッグハンドル) | `:::` 表示 | モックは表示のみ、並び替え未実装 |
| 商品名 | 商品名 | 行クリックで `dataPage` 遷移 |
| 商品コード | 商品コード文字列、空なら `-` | グレー小文字 |
| 発注先 | 発注先名 | グレー小文字 |
| 棚卸 | 棚卸ステータス | 「表示」(緑文字)/「非表示」(グレー文字)。プレーン色付きテキスト |
| 単位 | 単位文字列 | グレー文字 |
| 棚卸推奨単価 | 単価(円)。0なら `-` | グレー文字、3桁カンマ区切り |
| アクション | 「データ」「編集」ボタン | クリックで各画面に遷移 |

行クリック時の挙動:
- 行自体クリック → `dataPage` 遷移
- チェックボックスセル/アクションセルのクリックはバブリングを止め、行遷移を抑止

### ページング
- モックでは `< 1 2 3 >` + 「全N件中 1-10件表示」を表示するが、ロジック未実装(静的表示)。

## フィルタ・検索の組み合わせ

すべてのフィルタはAND条件で適用される:
1. 商品名検索（部分一致）
2. 棚卸ステータスフィルタ

選択状態変更時に即時 `renderTable()` を実行し、テーブル本体を再描画する。

## デザイン方針

- 棚卸ステータスの「表示/非表示」は **プレーンな色付きテキスト** で表現する(色付きpillバッジは使わない)
- テーブル列・検索フィルタ・詳細画面に「登録経路」は **設けない**（J-004 でUIから撤廃。`route` は内部分類としてのみ保持）
- フォント・色・余白は経営管理のデザインシステムに準拠
